2. Базовая архитектура (Как устроен проект)

Проект состоит из трёх файлов — «классической триады веб-разработки»:

  • index.html (Скелет и структура): Содержит разметку экранов: Главное меню, модальные окна (Обучение, Настройки, Выбор отрасли, Банкротство) и дашборд. Все модальные окна изначально имеют класс .hidden. Индикаторы шапки выводят баланс, чистую прибыль, репутацию, офис и шкалу морали.
  • style.css (Внешний вид, анимации и стили): Реализует тему Dark Enterprise / Cyberpunk. Построен на CSS Grid (3 независимые колонки дашборда) и Flexbox (выравнивание карточек, кнопок и бейджей). Содержит стили состояний: .project-card.locked, .bugged, .bar-bugged.
  • game.js (Бизнес-логика, математика и алгоритмы): Хранит состояние игры в объекте gameState (паттерн Single Source of Truth). Содержит каталог проектов directionProjectsCatalog (30 проектов, 4 тира). Управляет циклом, кадрами, прибылью, биржей, багами и моралью.

Блок 1: Состояние игры (gameState)

Зачем это нужно: Паттерн Single Source of Truth (Единый источник правды). Любое изменение сначала мутирует поле в gameState, а затем updateUI() синхронизирует DOM.

Блок 2: Формула финансового сальдо (calculateNetDailyProfit)

function calculateNetDailyProfit() {
    let passive = 0;
    const passiveMultiplier = gameState.upgrades.includes('server') ? 1.20 : 1.0;
    for (const p of gameState.projects) {
        if (p.completed) {
            let inc = p.passiveIncome || 0;
            if (p.hasBug) inc = Math.round(inc * 0.5); // Штраф за баг 50%
            passive += Math.round(inc * passiveMultiplier);
        }
    }
    let salaries = 0;
    for (const emp of Object.values(gameState.employees)) {
        salaries += (emp.count || 0) * (emp.salary || 0);
    }
    const serverDiscount = gameState.upgrades.includes('server') ? 0.70 : 1.0;
    let serverCosts = 0;
    for (const p of gameState.projects) {
        if (p.completed && p.serverCost) {
            serverCosts += Math.round(p.serverCost * serverDiscount);
        }
    }
    return passive - salaries - serverCosts;
}

Формула чистой прибыли в день:
Чистая прибыль = Сумма(ПассивныйДоход × K_bug × K_server) − Сумма(Зарплаты) − Сумма(СерверныйХостинг × K_discount)

Блок 3: Влияние морали на разработку (calculateMoraleProductivity)

function calculateMoraleProductivity() {
    if (gameState.morale >= 90) return 1.20; // +20% воодушевление команды
    if (gameState.morale < 40)  return 0.50; // -50% кризис выгорания (Burnout)
    return 1.0;                              // 100% штатная продуктивность
}

Как работает: При выгорании (дефицит бюджета) код пишется в 2 раза медленнее. Улучшения офиса (кофемашина, эргономичные кресла) поднимают мораль выше 90%.

Блок 4: Дерево технологий и разблокировка проектов (isProjectUnlocked)

function isProjectUnlocked(project) {
    if (!project) return false;
    if (project.minOfficeTier && gameState.officeTier < project.minOfficeTier) return false;
    if (project.minReputation && gameState.reputation < project.minReputation) return false;
    if (project.prereqId && !isProjectCompleted(project.prereqId)) return false;
    return true;
}

Как работает: Проект блокируется, если не соблюден уровень офиса, репутация или не сдан проект-предшественник. На карточке выводится бейдж с причиной блокировки.

Блок 5: Инциденты и хотфиксинг (handleDailyProjectBugs и fixProjectBug)

function handleDailyProjectBugs() {
    for (const p of gameState.projects) {
        if (!p.completed) continue;
        if (!p.hasBug && Math.random() < 0.015) { // 1.5% шанс сбоя в день
            p.hasBug = true;
            addLog(`Инцидент: в проекте "${p.name}" обнаружен критический баг!`, 'danger');
        } else if (p.hasBug) {
            const seniorCount = (gameState.employees.senior && gameState.employees.senior.count) || 0;
            if (seniorCount > 0 && Math.random() < 0.25) { // Senior-автотриаж
                p.hasBug = false;
                addLog(`Senior-тимлид устранил баг в проекте "${p.name}"!`, 'success');
            }
        }
    }
}

Блок 6: Стохастическая биржа с возвратом к среднему (calculateStockPrice)

function calculateStockPrice(currentPrice, trend = 0) {
    const meanReversion = (100.0 - currentPrice) * 0.012; // Стяжка к $100
    let delta = (Math.random() * 0.08 - 0.038) + (trend * 0.04) + (meanReversion / 100);
    if (currentPrice < 25) delta += 0.035;  // Отталкивание от дна
    if (currentPrice > 550) delta -= 0.035; // Отталкивание от потолка
    let nextPrice = currentPrice * (1 + delta);
    return Math.max(15, Math.min(600, Math.round(nextPrice)));
}
