## 2. Базовая архитектура (Как устроен проект)

Проект состоит из трёх файлов — «классической триады веб-разработки»:
1. **`index.html` (Скелет и разметка):**
   * Содержит разметку экранов: Главное меню, модальные окна (Обучение, Настройки, Выбор отрасли, Банкротство) и рабочий дашборд.
   * Все модальные окна изначально скрыты через CSS-класс `.hidden` и отображаются при манипуляциях с DOM.
   * Выводит индикаторы шапки: баланс, чистую прибыль/день, репутацию, офис и шкалу морали сотрудников.
2. **`style.css` (Внешний вид, анимации и стили состояний):**
   * Реализует современную темную тему (Dark Enterprise / Cyberpunk).
   * Построен на **CSS Grid** (3 независимые колонки дашборда) и **Flexbox** (выравнивание карточек, кнопок и бейджей).
   * Содержит селекторы состояний: `.project-card.locked` (заблокированные проекты с бейджами требований), `.project-card.bugged` (мигающая красная рамка инцидентов), `.bar-bugged` (янтарный цвет прогрессбара сбоя).
3. **`game.js` (Бизнес-логика, математика и алгоритмы):**
   * Хранит состояние всей игры в объекте `gameState` (паттерн *Single Source of Truth*).
   * Содержит каталог проектов `directionProjectsCatalog` (30 проектов, 4 тира).
   * Управляет игровым циклом, кадрами, расчетом чистой прибыли, биржей, багами и моралью.

## 3. Построчный разбор ключевых функций `game.js`

### Блок 1: Структура состояния (`gameState`)
```javascript
let gameState = {
    money: 6000,
    day: 1,
    reputation: 50,
    officeTier: 1,
    morale: 80, // Мораль команды: 0 - 100%
    upgrades: [],
    stocks: { price: 100, floatPrice: 100.0, history: [100], userOwned: 0, marketTrend: 0 },
    employees: { junior: { count: 0, salary: 60, devPower: 2 }, ... },
    projects: [...]
};
```
* **Зачем это нужно:** Паттерн *Single Source of Truth*. Любое изменение в игре сначала мутирует поле в `gameState`, а затем функция `updateUI()` реактивно проецирует новое состояние в HTML-элементы.
* **Строка `morale: 80`:** Стартовое значение морали сотрудников. При задержке зарплаты падает на 3%/день, при покупке кофемашины растет.
* **Строка `floatPrice: 100.0`:** Непрерывная вещественная цена акций. Исключает потерю точности при округлении малых процентных шагов.

### Блок 2: Формула финансового сальдо (`calculateNetDailyProfit`)
```javascript
function calculateNetDailyProfit() {
    let passive = 0;
    const passiveMultiplier = gameState.upgrades.includes('server') ? 1.20 : 1.0;
    for (const p of gameState.projects) {
        if (p.completed) {
            let inc = p.passiveIncome || 0;
            if (p.hasBug) inc = Math.round(inc * 0.5); // Штраф за баг 50%
            passive += Math.round(inc * passiveMultiplier);
        }
    }
    let salaries = 0;
    for (const emp of Object.values(gameState.employees)) {
        salaries += (emp.count || 0) * (emp.salary || 0);
    }
    const serverDiscount = gameState.upgrades.includes('server') ? 0.70 : 1.0;
    let serverCosts = 0;
    for (const p of gameState.projects) {
        if (p.completed && p.serverCost) {
            serverCosts += Math.round(p.serverCost * serverDiscount);
        }
    }
    return passive - salaries - serverCosts;
}
```
* **Формула чистой прибыли в день:**
  $$P_{\text{net}} = \sum (I_{\text{passive}} \cdot K_{\text{bug}} \cdot K_{\text{upgrade}}) - \sum \text{Salaries} - \sum (C_{\text{server}} \cdot K_{\text{discount}})$$
* **Что объяснять комиссии:** Выручка не растет бесконтрольно: завершенные продукты требуют серверных мощностей ($C_{\text{server}}$), а неисправленные баги снижают поток выручки вдвое ($K_{\text{bug}} = 0.5$).

### Блок 3: Влияние морали на скорость разработки (`calculateMoraleProductivity`)
```javascript
function calculateMoraleProductivity() {
    if (gameState.morale >= 90) return 1.20; // +20% воодушевление команды
    if (gameState.morale < 40)  return 0.50; // -50% кризис выгорания (Burnout)
    return 1.0;                              // 100% штатная продуктивность
}
```
* **Как работает:** Если мораль коллектива падает ниже 40% (например, из-за дефицита бюджета), разработчики пишут код в два раза медленнее. Улучшения офиса (кофемашина, эргономичные кресла) стабилизируют мораль выше 90%.

### Блок 4: Дерево технологий и валидация разблокировки (`isProjectUnlocked`)
```javascript
function isProjectUnlocked(project) {
    if (!project) return false;
    // 1. Проверка минимального уровня офиса
    if (project.minOfficeTier && gameState.officeTier < project.minOfficeTier) return false;
    // 2. Проверка уровня корпоративной репутации
    if (project.minReputation && gameState.reputation < project.minReputation) return false;
    // 3. Проверка завершения проекта-предшественника (Prerequisite)
    if (project.prereqId && !isProjectCompleted(project.prereqId)) return false;
    return true;
}
```
* **Как работает:** Проект блокируется, если не выполнен хотя бы один критерий. В интерфейсе на карточке проекта автоматически формируется бейдж с причиной блокировки (например: `Требуется: Коворкинг`, `Требуется: Репутация 70` или `Требуется: Завершить MVP`).

### Блок 5: Инциденты и хотфиксинг (`handleDailyProjectBugs` и `fixProjectBug`)
```javascript
function handleDailyProjectBugs() {
    for (const p of gameState.projects) {
        if (!p.completed) continue;
        if (!p.hasBug && Math.random() < 0.015) { // 1.5% шанс сбоя в день
            p.hasBug = true;
            addLog(`Инцидент: в проекте "${p.name}" обнаружен критический баг!`, 'danger');
        } else if (p.hasBug) {
            // Senior-разработчики имеют 25% шанс устранить баг автоматически
            const seniorCount = (gameState.employees.senior && gameState.employees.senior.count) || 0;
            if (seniorCount > 0 && Math.random() < 0.25) {
                p.hasBug = false;
                addLog(`Senior-тимлид устранил баг в проекте "${p.name}"!`, 'success');
            }
        }
    }
}
```
* **Что объяснять:** Моделирование технического долга. Баг можно починить вручную за фиксированную сумму `fixCost`, либо положиться на нанятых Senior-инженеров, выполняющих авто-триаж.

### Блок 6: Стохастическая модель биржи с возвратом к равновесию (`calculateStockPrice`)
```javascript
function calculateStockPrice(currentPrice, trend = 0) {
    const meanReversion = (100.0 - currentPrice) * 0.012; // Стяжка к $100
    let delta = (Math.random() * 0.08 - 0.038) + (trend * 0.04) + (meanReversion / 100);
    // Мягкое отталкивание от границ
    if (currentPrice < 25) delta += 0.035;
    if (currentPrice > 550) delta -= 0.035;
    let nextPrice = currentPrice * (1 + delta);
    return Math.max(15, Math.min(600, Math.round(nextPrice)));
}
```
* **Математика:** Процесс Орнштейна — Уленбека в дискретной форме. Цена не застревает на дне ($15) и не улетает в бесконечность ($600). При приближении к границам действует сила отталкивания.
* **Canvas:** Метод `drawStockChart()` проверяет `maxVal === minVal` и защищает от деления на ноль, рисуя горизонтальную линию уровня при плоской истории.

### Блок 7: Реактивность интерфейса и подсчет кадров (`updateUI`)
```javascript
function getTotalEmployees() {
    return Object.values(gameState.employees).reduce((sum, emp) => sum + (emp.count || 0), 0);

```
* **Почему важно:** Функция `updateUI()` не принимает аргументов и рассчитывает общее число сотрудников динамически из `gameState.employees`. Это исключило баг сброса счетчика сотрудников в 0.
* **Кнопка клика:** При покупке апгрейда «Оптоволоконный гигабит» надпись кнопки мгновенно меняется с `+$50` на `+$100`, а клик приносит \$100.

## 6. Памятка по демонстрации на защите (Сценарий на 1 минуту)

1. **Запуск:** Откройте `index.html` двойным кликом в Google Chrome или Яндекс Браузере.
2. **Шаг 1 (Интро):** Нажмите «Играть», введите название компании и выберите направление (например, «IT и Нейросети»).
3. **Шаг 2 (Клик-работа):** Нажмите несколько раз кнопку «Писать код вручную (+$50)», заработайте стартовый капитал.
4. **Шаг 3 (Кадры и проект):** Наймите 1 Junior-разработчика, перейдите в «Продукты» и начните разработку «AI Chatbot MVP». Обратите внимание комиссии, как прогрессбар заполняется автоматически.

6. **Шаг 5 (Дерево технологий):** Покажите заблокированные проекты 2-го и 3-го тира и объясните, что для них нужен переезд в Коворкинг или Бизнес-центр.
