## 2024-10-01 - Interactive Element States and Semantics
**Learning:** This static vanilla JS application lacked basic interaction feedback: settings checkboxes were un-clickable via text because they used `<span>` instead of `<label>`, making the clickable target very small. Furthermore, while the JS frequently added `disabled` attributes to buttons (e.g., when requirements were not met), there were no visual `:disabled` CSS rules to communicate this, confusing users. Finally, keyboard navigation lacked visual indicators due to missing `:focus-visible` outlines.
**Action:** When working on settings UI, always wrap descriptions in `<label>` linked by `for` ID to inputs to expand hit area. For custom buttons or systems heavily relying on JS state toggles, proactively add `:disabled` and `:focus-visible` styles early in the design system to ensure accessible and intuitive interactions.
